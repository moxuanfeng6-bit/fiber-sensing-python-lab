# 光谱平滑与中心定位稳定性比较

**Spectrum Smoothing and Center Localization Stability**

这是一个 Python 科学计算学习项目，使用 SG（Savitzky–Golay）平滑与自动寻谷，比较不同方法对光谱谷中心的定位结果。项目包含模拟实验和自定义 CSV 光谱分析两部分，可用于学习光谱预处理、特征定位和重复性评价。

主要代码：`spectrum_center_stability.ipynb`。

## 比较的三种方法

| 方法 | 实现 | 含义 |
| --- | --- | --- |
| 原始最低点 | `np.argmin(intensity)` | 直接取测量光谱中光强最低的采样点 |
| SG最低点 | `savgol_filter()` + `np.argmin()` | 平滑后取最低采样点 |
| SG自动寻谷 | `savgol_filter()` + `find_peaks(-smoothed)` | 平滑后根据突出度和最小间距筛选局部谷 |

三种方法输出的中心都是采样点对应的波长，当前未加入亚采样定位或谷形拟合。对于只有一个明显谷的光谱，后两种方法可能得到相同结果。

## 第一部分：模拟实验

生成中心为 **1550.25 nm** 的高斯形光谱谷，在 **1548～1552 nm** 范围采样401个点。对同一条理想光谱分别添加20组正态随机噪声，模拟重复测量。

- 噪声均值为0，标准差为0.02。
- 随机种子为42，方便复现实验。
- SG窗口长度为11，多项式阶数为2。
- 自动寻谷使用 `prominence=0.1`、`distance=30`。
- 每次测量中，三种方法处理同一份带噪声数据。

程序输出有效测量次数、平均定位误差、平均绝对误差（MAE）、样本标准差和自动寻谷异常次数，并绘制20次定位误差对比图。

定位误差定义为：

```text
定位误差（pm）=（检测中心波长 - 真实中心波长）× 1000
```

## 第二部分：分析自己的CSV光谱

支持一条或多条光谱。单条光谱可进行平滑和寻谷；评价重复性需要至少两次有效测量。用于比较重复性的各列应来自相同实验条件下、同一个目标谷的重复测量。

### CSV格式

波长列名为 `wavelength_nm`，单位为nm。其余指定列分别保存每次测量的光强，每行的波长与光强一一对应。

```csv
wavelength_nm,intensity_1,intensity_2,intensity_3
1549.80,0.90,0.91,0.89
1549.90,0.65,0.66,0.64
1550.00,0.40,0.41,0.39
1550.10,0.60,0.61,0.59
1550.20,0.88,0.87,0.89
```

以上仅用于说明列结构，不是完整的分析数据；默认窗口为11，需要至少11个有效采样点。

输入需为数值数据、无缺失值或无穷值，波长严格递增且不重复，并近似等间隔。不满足要求时，代码会提示错误，需要先整理数据。排序时必须同步排列对应光强。

### 配置自己的数据

```python
csv_path = 'my_spectrum.csv'
intensity_columns = ['intensity_1', 'intensity_2', 'intensity_3']

wave_min, wave_max = 1548, 1552
window_length = 11
polyorder = 2
prominence = 0.1
distance = 30
reference_center = None
```

- `csv_path`：文件路径。相对路径以Notebook当前工作目录为起点，也可以使用绝对路径。
- `intensity_columns`：需要处理的光强列名，必须与CSV一致。只有一条光谱时填写一个列名即可。
- `wave_min`、`wave_max`：目标谷所在的分析范围，应先选定一个目标谷。
- `window_length`：SG窗口的采样点数。本项目要求奇数，且不超过截取后的数据点数。
- `polyorder`：局部多项式阶数，必须小于窗口长度。
- `prominence`：谷的突出度要求，与光强数值尺度有关，需要按实际数据调整。
- `distance`：检测点之间的最小采样间隔数，单位不是nm。
- `reference_center`：已知参考中心，单位nm；未知时填写 `None`。

第二部分默认读取 `example_spectra.csv`。请自行准备数据文件并修改路径；Notebook不会自动生成这个文件。如果使用模拟示例CSV，应将它标明为模拟数据。

### 检测与统计规则

自动寻谷恰好找到一个谷时，记录其中心；找到0个或多个谷时，将本次中心记录为 `NaN`，同时保留检测到的谷数量。

| 指标 | 解释 |
| --- | --- |
| 有效/异常数量 | 各方法获得有效中心和无效中心的次数 |
| 平均中心波长 | 有效中心波长的平均值，单位nm |
| 样本标准差 | 重复测量中心的分散程度，使用 `ddof=1`，单位pm |
| 平均误差 | 检测中心相对参考中心的平均有符号偏差，单位pm |
| MAE | 定位误差绝对值的平均值，单位pm |

没有参考中心时，仅统计中心和重复性，不计算平均误差与MAE。有效结果不足两个时，样本标准差为空。自动寻谷的误差统计只使用有效结果，因此需同时查看异常数量。

## 如何理解结果

- 标准差小表示重复性较好，不代表一定接近真实中心。
- MAE小表示在有参考值的条件下，定位更接近参考中心。
- 平滑窗口过大可能改变谷形；应结合图形和统计结果调整。
- `prominence`、`distance` 筛选的是检测位置，不会删除原始光谱中的谷。
- 真实测量的波动可能来自仪器漂移、环境和样品变化，不能全部归因于定位算法。

本项目用于学习和方法比较，尚未使用真实实验数据进行系统验证；模拟实验的结论不代表所有光谱的表现。
